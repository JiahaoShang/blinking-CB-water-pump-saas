# 企业知识管理第一批验收记录

状态（2026-10-11）：第一批代码及其余约定验收完成；真实模型联调 B5 按用户决定待验证。范围为 PRD 第 8 节第一批；真实模型联调 B5 按用户决定待验证，不计通过。未部署、未进行外部渠道网络联调。

## 已实现与独立验证

- 通用文章/FAQ、产品/服务知识的真实保存、发布快照、草稿编辑、历史内容查看与恢复为新草稿；恢复不覆盖历史，不改变当前发布版本。
- TXT/Markdown/CSV 保存真实私有原件并导入正文，核对后保存或发布；PDF/Word 仅原件登记和人工整理，不承诺自动识别。
- 全企业成员阅读；管理员及获产品管理授权成员编辑、发布和授权。跨企业访问、越权写入由服务端拒绝。
- 对外 AI 使用须满足已发布、对外、授权、未到期及处理成功。产品还要求发布快照与当前字段均对外且核准，快照来源未被禁止。模型返回后再次校验版本和撤销，不能通过草稿换来源绕过。
- 可选精确到期时间，留空长期有效；停用、关闭授权和到期立即排除，员工阅读及历史保留。新渠道 AI 默认关闭及开启前资料确认沿用原规则。
- 统一知识列表和上下文添加入口、分类折叠菜单、线稿图标、动画和键盘访问；搜索一键清空只清关键词，保留用途/分类等筛选并刷新结果、返回搜索焦点。
- 已发布可用保留原绿色；不可用中性蓝灰色并解释原因。待发布草稿不替换列表、详情和客户问答中的已发布内容；有草稿时仍可停用。
- 处理结果绑定真实版本与内容分块，提供失败重试；没有以假计时器制造可用状态。问答入口未连接模型时明确提示，不能产生预置假回答。

## 真实界面走查

在原演示库的隔离副本进行，管理员与普通成员分别登录，未向真实模型或外部平台发送数据。

- 文章录入→保存草稿→详情回读→内部发布显示不可用与内部原因。
- 对外授权发布的确认框支持取消/Escape和焦点返回；取消保留输入，确认后持久化新版本。
- 编辑已发布内容只产生草稿，详情仍展示旧发布内容；发布新版切换版本；历史展开可读旧正文，恢复创建新草稿。
- 真实 TXT 文件通过文件选择器上传，编辑器出现文件内容，来源页可见私有下载原件。
- 搜索无结果→键盘触发清空→关键词清空、其他筛选保留、列表刷新、焦点返回。
- 分类入口出现对应新增选项；折叠菜单可用空格键展开。
- 已发布且有待发布草稿仍可停用；重新启用保留原发布版本及待发布草稿；关闭授权显示蓝灰不可用。
- 普通成员读取内部资料；无编辑/发布按钮，直接编辑 URL 也被拒绝。
- 桌面列表与手机列表/详情已验证；390px 标题说明整行显示，320px 与390px 无横向溢出。内部和未授权资料详情发布直接完成；内部重新启用直接完成；停用及对外开启授权仍显示确认。最后七项 HTTP 场景另验证对外授权发布/重新启用必须确认、确认条件取正确版本。
