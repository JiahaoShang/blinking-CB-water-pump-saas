## 1. 一句话目标

把「公开产品页怎么生成」从写死在代码里，变成一条可配置、可审、可版本的链路：

> **平台基础模板 → 企业按品类创建模板 → 编辑（展示字段 / 页面区块 / 提示词）→ 保存草稿 → 买方视角预览 → 授权成员核准 → 发布为模板版本 → 产品发布时引用并冻结该版本**

模板决定"页面长什么样、提取与展示哪些字段"，**不放松**「技术事实必须有出处、未核准不得对外」的既有硬线（V1-03 验收③）。

## 2. 范围

**本设计覆盖（首版主体）**
1. 企业模板库：列表、从平台基础模板创建、按品类管理（一企业一品类一个在用模板）。
2. 模板编辑器：展示字段与分组、页面区块（开关/顺序/标题中英文案）、提示词、保存草稿。
3. 买方视角预览（站内、带预览标识，不对外）。
4. 提交核准 → 管理员核准并发布为模板版本；撤回；版本历史。
5. 产品页联动：产品发布时引用并冻结模板版本；已发布页面与旧 RFQ 依据不被模板新版本静默改写。
6. 全程审计（操作记录页可见中文标签）。

**明确不做（首版；如需要另行登记）**
- 自由布局 / 自定义 HTML / 拖拽建页；新增字段类型或字段库扩容（首版字段库=现有 8 字段）。
- AI 生成整页文案、AI 提示词"自由注入"（提示词仅覆盖既定两个槽位，见 Q2）。
- 3D 生成、CAD 参数化等长期能力（F-10/F-11，仍属长期代办）。
- 跨企业模板市场 / 行业模板库（F-14 仅保留方向，系统性问题另开专题）。

**硬边界（不变式，实现时逐条回归）**
- 模板编辑不能绕过字段的出处与核准（未核准字段/事实照旧不进页面、匹配、问答）。
- **默认模板渲染 = 现状页面**（结构等价，回归锁测试；防止"上了模板库、页面悄悄变样"）。
- 模板只控制"提取口径 + 呈现"，不改变权限、审计、隔离的任何既有约束。
- 未核准品类的产品不能被模板引用（品类门禁沿用 V1-02 的 `get_approved_category`，即 F-23 落地）。

## 3. 概念模型

| 概念 | 说明 |
| --- | --- |
| **平台基础模板** | 平台内置、只读、作为复制起点。首版内置 1 个：「水泵（基础）」，内容=把**现状页面结构与字段口径原样固化**。 |
| **企业模板** | 某企业某品类的一份模板。状态机：`草稿` → `待核准` → `已发布`（含已发布版本号）→ 可 `撤回`；同一企业同一品类**至多一份**在用模板。 |
| **模板草稿** | 正在编辑的完整配置（随时保存；只有编辑者可见变更影响，未发布前对买方无任何影响）。 |
| **模板版本** | 核准发布时的不可变快照（含内容 JSON、核准人、时间、版本号 vN）。历史版本只读。 |
| **产品引用** | 产品**发布**时引用「该产品已核准品类」对应模板的**已发布版本**，并把模板版本号写进产品发布快照。模板出新版本 ≠ 已发布页面变化；需对产品重新发布才套用。 |

**「品类工作流」在本文档中的含义**：本系统里该品类「资料准备 → 提取口径 → 核准发布 → 页面呈现」链路中**允许配置的部分**（首版=提取/展示字段集、页面区块、AI 提示词三件）；核准与出处的硬性要求、权限与审计**不可配置**。

**状态机（文字图）**
```
（从基础模板复制 / 空白创建）
        │
        ▼
     草稿 ──保存/预览（循环）──► 提交核准 ──核准并发布──► 已发布 vN
        ▲                        │退回                    │
        └──────────（修改）───────┘                        │撤回（停止新引用；已引用的产品发布不动）
                                                          ▼
                                                    已撤回（可继续编辑→重新发布 vN+1）
```

## 4. 页面与交互设计（卖家侧）

> 线框见配套 HTML（四个屏与下文一一对应）。所有页面挂控制台「产品经营」分组，新增导航项 **「品类模板」**（`/admin/templates`）。

### P1 模板库列表 `/admin/templates`
- 焦点卡（照控制台惯例）：按状态给出"下一步"——无模板→「从基础模板创建」；有草稿→「继续编辑」；待核准→「等待管理员核准」（管理员登录则显示「去核准」）；已发布→「查看 / 编辑新草稿」。
- 模板条目行（`.simple-item`）：**品类 · 模板名** + 状态徽标（草稿 / 待核准 / 已发布 vN / 已撤回）+ 一行摘要（更新人 · 时间 · 引用产品数）+ 右侧「下一步」按钮。
- 「从基础模板创建」：选择**已核准品类**（下拉，只出现已核准品类；空则引导先去产品页核准品类）→ 选择起点（水泵基础模板 / 空白）→ 生成本企业模板草稿。
- 多个品类→多条目；顶部小字注明「模板只影响新发布，已发布页面保持其发布时的版本」。

### P2 模板编辑器 `/admin/templates/{id}`
- 顶栏：返回列表 + 模板名 + 品类 + 状态徽标；右侧操作组：
  **保存草稿**（所有人可点，作者记录）· **买方视角预览**（新开预览页）· **提交核准**（编辑者）· **核准并发布新版本**（仅管理员，取代"提交核准"出现在管理员视图）· **撤回**（管理员；已发布时可见）。
- 提示条（状态化）：草稿未发布→「未发布：当前修改不影响任何对外页面」；待核准→「已提交，等待管理员核准」；有新草稿的已发布模板→「有未发布的修改；已发布页面仍使用 vN」。
- **区块一：展示字段与分组**（表格行=字段）
  - 每行：字段名（固定键）· 显示开关 · 分组下拉（四组）· 中文标签输入 · English label 输入 · 单位提示输入 · 行内顺序（上移/下移）。
  - 首版字段库=现有 8 字段（流量范围/扬程范围/介质适用条件/材质/功率/介质温度/性能曲线目录点/安装尺寸）；「必填（发布缺项提示口径）」沿用现状 4 项，不在模板里放开（避免绕过硬线）——界面注明。
  - 底部注：字段值仍来自"资料 → 逐项核准"，模板只控制展示与提取提示口径；**编辑模板不会改变任何已核准事实**。
- **区块二：页面区块**（行=区块；清单冻结现状：hero、规格表、图纸（2D/3D）、应用场景、定制能力、制造与质检、认证、对比、资料下载、FAQ、优势细项——**以实现冻结清单为准**，共约 11–14 项）
  - 每行：区块名 · 启用开关 · 上移/下移 · 中文标题 · English title（可留空=用平台默认文案，界面显示默认值 placeholder）。
- **区块三：提示词**（AI 模式专用）
  - 两个槽位：**需求抽取提示词**（买家消息→需求草稿）、**字段定位提示词**（买家提问→定位已发布字段）。
  - 每个槽位：默认提示词（只读展示）+ 企业覆盖编辑框 + 「恢复默认」。
  - 显著说明：**当前 AI 模式=可选（默认规则引擎）；规则模式下提示词不生效、仅记录**；提示词编辑**永远不会**让未核准内容对外（答案/抽取结果仍走既有审核口径）。
- **区块四（折叠）**：模板版本历史——vN · 核准人 · 时间 · 与上一版差异摘要（字段/区块/提示词变化项数，可展开逐项）。

### P3 买方视角预览 `/admin/templates/{id}/preview`
- 完整买方产品页渲染 + 顶部固定黄色横幅「**模板预览 · 未对外发布**」。
- 预览数据：选择一个同品类的**已发布产品**用其已核准字段/文件渲染（下拉切换；没有已发布产品时用占位示例并标注）。
- 预览与真实买家的差异集中在此页明示：预览不走买家会话、不产生埋点、不对外可见。

### P4 产品页联动（产品核对页 `/admin/products/{id}` 新增「品类模板」卡）
- 显示：本产品品类 → 将引用的模板与版本（`水泵模板 v2（发布时冻结）`）；无企业模板→「将使用平台基础模板」；品类未核准→「先在产品页核准品类，才能引用模板」。
- 已发布产品若已有**更新的模板版本**：显示「有新版模板可用；重新发布后生效（当前页面不受影响）」。

### P5 操作记录
- 新事件进既有 `/admin/audit`：`登记模板` / `保存模板草稿` / `提交模板核准` / `核准并发布模板版本` / `撤回模板` / `恢复默认提示词`（中文标签），租户隔离、可筛选。

## 5. 数据模型（草案）

```sql
-- 模板（企业模板 + 平台基础模板共用一张表）
templates(
  id, tenant_id,                -- 平台行 tenant_id='' 且 is_platform=1
  is_platform INTEGER,          -- 1=平台基础模板（只读）
  category TEXT,                -- 绑定的已核准品类
  name TEXT,
  status TEXT,                  -- draft / pending_approval / published / withdrawn
  draft_json TEXT,              -- 当前草稿内容（见下）
  draft_updated_by, draft_updated_at,
  published_version INTEGER,    -- 最新已发布版本号（0=从未发布）
  created_by, created_at, updated_at,
  UNIQUE (tenant_id, category)  -- 企业行唯一；平台行另按 category 唯一
)

-- 模板版本（发布快照，不可变）
template_versions(
  id, tenant_id, template_id, version,
  content_json TEXT,            -- 发布时冻结的完整内容
  status,                       -- published / superseded / withdrawn
  approved_by, approved_at, created_by, created_at,
  UNIQUE (template_id, version)
)
```

**内容 JSON（draft_json / content_json 同构）**
```json
{
  "fields": [
    {"key": "flow_range", "show": true, "group": "hydraulic",
     "label_zh": "流量范围", "label_en": "Flow range", "unit_hint": "m³/h", "order": 1}
  ],
  "groups": [ {"key": "hydraulic", "title_zh": "水力性能", "title_en": "Hydraulic performance", "order": 2} ],
  "blocks":  [ {"key": "downloads", "enabled": true, "order": 6,
                "title_zh": "", "title_en": ""} ],
  "prompts": { "requirement_extraction": "", "field_selection": "" }
}
```
- 字段/分组/区块的 **key 集合首版固定**（=现实现冻结清单）；模板只改 show/顺序/标签文案。
- 产品发布快照（`product_versions.snapshot_json`）追加：
  `"template": {"template_id", "template_version_id", "version", "source": "enterprise|platform"}`。
- 审计动作：见 P5 清单。

## 6. 权限与门禁（建议默认，见 Q1）

| 动作 | 建议（方案 A，保守） |
| --- | --- |
| 查看模板库 / 编辑草稿 / 预览 / 提交核准 | 持「产品管理」模块的员工 + 管理员（`/admin/templates` 映射 products 模块） |
| **核准并发布模板版本 / 撤回** | **仅管理员** |
| 平台基础模板 | 全员只读 |

- 跨租户：模板与版本全部租户隔离；平台基础模板对所有企业只读可见。

## 9. 待你拍板（Q1–Q7，含推荐）

> 回复格式随意，逐题即可。

**Q1 权限（编辑 / 核准）**
- A（推荐）：编辑+提交=持「产品管理」模块的员工与管理员；**核准发布与撤回=仅管理员**（模板决定所有公开页形态，先保守，与成员管理同级）。
- B：核准也放开给持「产品管理」模块的员工。
- C：其它组合（请说明）。

**Q2 提示词首版范围**
- A（推荐）：只放两个既定槽位（需求抽取 / 字段定位），且**仅 AI 模式生效**；规则模式界面明示"不生效、仅记录"；不做自由注入。
- B：再加一个"资料抽取提示词"槽位（当前资料抽取是规则引擎，无 AI 调用——会有"存了但没用"的假配置风险）。
- C：首版不做提示词编辑（登记到 Phase 2）。

**Q3 区块/字段编辑深度**
- A（推荐）：区块=开关+顺序+中英标题；字段=开关+分组+中英标签+单位提示+顺序；**不新增**字段类型/自由 HTML/布局拖拽。
- B：做更深（自由排序表格/多套字段库），工期与风险显著上升。

**Q4 产品与模板的引用方式**
- A（推荐）：**按品类自动引用**——产品发布时取「其已核准品类」对应的企业模板已发布版本；无企业模板→平台基础模板；发布快照冻结版本号。简单、不会漏配。
- B：每个产品手动选择模板（更灵活，多一层配置与校验）。
- C：A + "产品可显式指定跟随某个早期版本"（可后续再加）。

**Q5 平台基础模板的起点**
