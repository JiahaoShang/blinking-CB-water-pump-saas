## 1. 一句话目标（修订）

> 让任何行业的普通业务人员，**不靠说明书、十分钟内**，把「买家点开产品后看到的详情页」设置成自己想要的样子；看不中意的部分随时改，改动只在"发布"后才对买家生效。

## 2. 位置与信息架构（改）

- 导航一级分组 **「创意中心」**（icon `i-palette`，位于「产品经营」与「经营分析」之间），当前仅一个子项 **「详情展示页」**（面包屑：创意中心 / 详情展示页）。创意中心作为"工作区域"后续可容纳更多创意类功能，本稿只做这一个。
- 权限：新模块 `creative`（可授权给员工；管理员默认拥有）。**编辑/预览=持 creative 模块；提交给管理员确认；确认上线与撤回=仅管理员**〔Q1〕。产品管理模块（`products`）不自动获得本页访问。
- 内部地址：`/admin/creative/pages`（列表）与 `/admin/creative/pages/{id}`（编辑）。本稿继续用"模板库/模板"作为内部术语；**界面上一律用"详情展示页 / 展示页"**（§4.2）。

## 3. 行业通用化设计（新）

设计原则：**这份功能对"工业品"零假设**——凡是需要"给买家看的固定详情页"的企业都能用。

1. **参数=企业自定义**。展示页里要展示哪些"规格参数"，由企业自己定：从**推荐参数池**一键添加（型号、材质、尺寸、重量、颜色、功率、电压、容量、精度、接口、防护等级、工作温度…通用词），或直接**自定义**（中文名 + English + 单位，可留空）。参数即"提取与展示口径"：上传资料时按参数名（及别名）识别候选，人工确认后才展示——出处与核准要求一字不松。
2. **板块=通用内容块库**。页面由通用板块拼成：首屏（固定）、参数规格、图片/图库、图纸与尺寸、应用场景、定制能力、制造与质检、认证与资质、竞品对比、资料下载、常见问题…… 可增删、排序、改标题（中英可留空用默认）。
3. **标准模板（平台基础模板）去行业词**：「标准模板（推荐）」内置上述通用板块 + 一小撮示例参数，**鼓励修改**；不叫"水泵模板"，不对任何行业背书。
4. **品类机制保留但弱化表述**：平台已有"产品品类"概念（产品管理里核准）。本页把它用作**绑定单位**——"**这类产品**用这份展示页"；名称默认=品类名（如「离心泵（端吸）· 展示页」，企业可改）。未核准品类的引导：给「去产品管理核准品类 →」的链接，不在此处另开一条绕过审核的创建通道。
5. **边界（如实说明，不做假配置）**：自定义参数首版覆盖 **资料提取匹配（文本级）→ 人工录入 → 页面展示 → 缺项提示**；**智能问答与匹配的字段选择仍沿用既有清单**，"自定义参数的问答支持"登记为后续增强。AI 助手设置对自定义参数同样按文本级生效。

## 4. 面向非技术人员的极简与引导（新·核心）

### 4.1 十条简化原则

1. **一句话说清这是什么**：每页顶部一句大白话（"买家点开你的产品后看到的页面，就在这里设置"）。
2. **预设优先**：默认给一份可用的「标准模板」，用户改而不是从零造。
3. **三步走**：选参数 → 排内容 → 看效果；顶部常驻步骤条，首次进入有教练条（"跟着做，大约 5 分钟"）。
4. **一屏一件事**：编辑区只有两大块（参数、内容）；其余全部收进折叠区。
5. **渐进披露**：AI 助手设置、分组名称、版本记录等**默认折叠**，写清楚"不改也完全能用"。
6. **大白话微文案**：每个控件旁边一句话说明"它是干嘛的"；不用行业黑话、不用开发词。
7. **自动保存**：没有"保存"按钮的负担；顶部一行小字"已自动保存 · 15:04"。
8. **安全语义天天讲**：改动**不影响线上**，直到点"发布"；线上版本随时可看。
9. **状态说人话**：不用"草稿/待核准/pending"这类词（见 §4.4 对照表）。
10. **少即是多**：徽标从简、数字从简；主按钮永远只有一个"下一步"。

### 4.2 术语替换表（界面主路径不再出现左列）

| 内部/旧稿用语 | 界面用语 |
| --- | --- |
| 模板 / 品类模板 | 详情展示页（或"展示页"） |
| 字段 | **参数** |
| 区块 | **内容板块**（或"板块"） |
| 提示词 | **AI 助手设置**（进阶区，默认折叠） |
| 草稿 / 未发布草稿 | **未发布的改动** |
| 提交核准 / 核准并发布 | **提交给管理员** / **确认上线**（管理员侧） |
| 发布（模板版本） | **发布**（微文案解释：发布后买家才会看到新版本） |
| 模板版本历史 | **版本记录** |

### 4.3 三步引导流（编辑器内常驻）

```
① 选参数 ──→ ② 排内容 ──→ ③ 看效果（预览并提交）
"展示哪些规格"   "页面有哪几部分"    "买家看到的样子"
```
- 三步随时可来回切换；每步底部有大按钮「去第②步 →」；完成度用 ✔ 轻量标注。
- 首次进入编辑器：顶部教练条「第一次设置？跟着三步做即可，大约 5 分钟。你也可以随时点右上角『看效果』。」
- 创建入口极简：首页每行一个"开始设置"；创建时只问两件事——**这个展示页给哪类产品用**（下拉）＋ **起个名字**（默认=品类名）＋ 起点（标准模板/空白），一个表单一次问完。

### 4.4 状态对照（界面文案）

| 内部状态 | 界面说人话 | 主按钮（该状态的下一步） |
| --- | --- | --- |
| 无模板 | 尚未设置展示页 | **开始设置** |
| 有未发布改动 | 有改动还没发布（线上仍是旧版） | **继续编辑** |
| 已提交待确认 | 已提交，等待管理员确认 | 管理员看到：**去确认**；员工看到：等待中（可撤回提交） |
| 已发布 | 已上线 vN | **查看**（产品页有更新未套用时给"重新发布"提示） |

### 4.5 上手剧本（走查用，验收点 15）

新员工登录 → 创意中心 / 详情展示页 → 点"开始设置"（30 秒表单）→ 三步引导：加两个参数、开一个板块、点"看效果" → 提交给管理员 → 管理员"确认上线" → 产品重新发布后买家页生效。全程不出现任何技术词，不需要读文档。

## 5. 页面与交互（五屏，对照线框）

### P1 「详情展示页」首页 `/admin/creative/pages`
- 标题 + 一句话说明；**示例入口**：「看一份示例展示页」。
- 引导卡（无任何设置时）："三步做出你的产品展示页" ①选参数 ②排内容 ③看效果 + 大按钮「开始设置」。
- **按品类列行**（每个已核准品类一行）：`离心泵（端吸）· 展示页`｜状态说人话（§4.4）｜更新人与时间｜主按钮（按状态的下一步动作）。无展示页的品类行 = "尚未设置展示页 [开始设置]"。
- 页脚小字："已上线的展示页：改动要发布后才生效；旧询价与历史记录不受影响。"

### P2 编辑器 `/admin/creative/pages/{id}`
- 顶栏：返回 · 名称（可就地改）· 状态行（"有改动还没发布 · 线上仍是 10-02 版本"）· 「已自动保存」；主按钮组：**【看效果】**（次要）与**【提交给管理员】**（主，状态化；管理员登录时显示**【确认上线】/【撤回】**）。
- 步骤条：① 选参数 / ② 排内容 / ③ 看效果（③即预览页）。每个步骤页顶部一句微文案。
- **① 选参数**：参数卡片列表（每张卡：参数名中英 + 单位 + 显示开关 + 上下移 + ⋯展开编辑/删除）；「从推荐里加」 chips 区（点一下加一个）；「+ 自定义参数」。微文案："这些是买家在页面上看到的规格。**数值来自你上传的资料，你确认过才会展示**。"
- **② 排内容**：内容板块卡片列表（板块名 + 一句话说明 + 开关 + 上下移 + 改标题）；「从板块库添加」chips 区。微文案："决定买家看到的页面有哪几部分、谁在上面。"
- **③ 看效果** = 预览页（P3），编辑器里的按钮直接新开。
- **折叠区（默认关闭）**：『AI 助手设置（进阶）：不改也完全能用』（两个文本框 + 恢复默认 + 说明"只在启用 AI 助手时生效"）；『分组名称』（把参数按组归类，默认一组"规格参数"）；『版本记录』（vN · 确认人 · 时间 · 与上一版差异摘要）。

### P3 看效果（预览）`/admin/creative/pages/{id}/preview`
- 黄色横幅：「**预览 · 买家视角（未发布）**——用未发布内容 + 已核准资料渲染；不对外、不产生数据」。
- 顶部下拉：用哪个已发布产品试看；中文/EN 一键切换核对。
- 与真实买家的差异集中在此页明示：预览不走买家会话、不产生埋点、不对外可见。

### P4 产品页联动（产品核对页新增「展示页」卡）
- 显示：本产品**这类产品**用的展示页与版本（"发布时锁定 · 引用人"）；无企业展示页→"将使用平台标准模板"；品类未核准→"先去核准品类"（带链接）。
- 有更新版本未套用 → "展示页有新版本：重新发布产品后生效（**当前线上不受影响**）"。

### P5 操作记录
- 事件中文标签沿用操作记录页：`登记展示页 / 保存改动 / 提交确认 / 确认上线 / 撤回 / 恢复默认 AI 设置`（租户隔离、可筛选）。

## 6. 数据模型（微调）

```sql
-- 展示页（企业 + 平台标准模板共用；内部仍称 templates）
templates(
  id, tenant_id, is_platform, category, name,
  status,                -- draft / pending_approval / published / withdrawn（界面按 §4.4 翻译）
  draft_json, draft_updated_by, draft_updated_at,
  published_version, created_by, created_at, updated_at,
  UNIQUE (tenant_id, category)
)
template_versions(id, tenant_id, template_id, version, content_json,
  status, approved_by, approved_at, created_by, created_at, UNIQUE(template_id, version))
```

**内容 JSON（v0.2：参数为自定义结构）**
```json
{
  "params": [
    {"key": "p_material", "label_zh": "材质", "label_en": "Material", "unit": "",
     "show": true, "group": "specs", "order": 1, "aliases": ["材料", "构造"]}
  ],
  "groups": [{"key": "specs", "title_zh": "规格参数", "title_en": "Specifications", "order": 1}],
  "blocks": [{"key": "specifications", "enabled": true, "order": 2, "title_zh": "", "title_en": ""}],
  "advanced": {"ai_prompts": {"requirement_extraction": "", "field_selection": ""}}

```
- 参数 `key` 自动生成；`aliases`（提取匹配用别名）由推荐池预填、可留空，界面不暴露该字段（进阶文档说明）。
- 发布快照 `product_versions.snapshot_json` 追加 `"template": {template_id, template_version_id, version, source}`（与 v0.1 相同）。
- 模块：`GRANTABLE_MODULES` 增加 `("creative", "创意中心")`；`/admin/creative` 前缀 → `module:creative`。

## 7. 硬边界与不变式（保留）

1. **默认（标准模板）渲染 = 现状页面**：回归锁，防止"上了设计器、页面悄悄变样"。
2. 未核准事实不进页面、匹配、问答；参数自定义不放松出处与核准（一句话：**展示可自定义，事实不放松**）。
3. 未发布改动不影响线上；发布冻结版本；旧 RFQ 与历史快照不被静默改写。
4. 仅管理员可"确认上线/撤回"；模板与版本全租户隔离；平台标准模板全员只读。
5. 界面主路径无技术术语（走查项）；任何"高级"能力都默认折叠且注明"不改也完全能用"。
