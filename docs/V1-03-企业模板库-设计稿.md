**状态**：设计草案 v0.3（**仍未开工**）。v0.2 已获拍板（见 §10 拍板记录），本稿落实拍板结果 ＋ 你本轮两条 UI 建议：
- **命名**：创意中心 › **产品展示页**（原"详情展示页"作废）；

**配套线框（已更新）**：`design/template-library-wireframe/index.html`（五屏：首页 / 选参数 / 排内容 / 看效果 / 产品页联动）。

## 1. 一句话目标

> 让任何行业的普通业务人员，**不靠说明书、十分钟内**，为企业产品库中的产品做出"买家点开就能看到的"产品展示页；改动画质所见即所得，**改动只在"发布"后才对买家生效**。

## 2. 位置、命名与信息架构

- 导航一级分组 **「创意中心」**（icon `i-palette`）→ 子项 **「产品展示页」**。
- **权限（拍板 q1:a）**：新增可授权模块 `creative`；**授权/收回的操作入口仍在「成员管理」（企业管理内）**，与其它模块并排勾选；创意中心内部不设任何权限设置控件。管理员默认拥有；**确认上线 / 撤回 = 仅管理员**。
- **区域顶部模块条（本轮重点）**：
  ```
  [ 首页 ]        [ 选参数 ]──▶[ 排内容 ]──▶[ 看效果 ]──▶[ 产品页联动 ]
  ```
  - **全区域唯一一条**：位于区域最顶部（页面标题之上），任何界面都**不重复出现**第二排模块导航（已修复线框中上下两排重复的问题）；
  - **不带数字标识**；四个流程模块之间用**连线（带箭头）**表达递进关系；
  - 在「首页」时：四步链路以浅色显示（让用户先"看到"整个旅程）；进入某份展示页的编辑后：链路可点击切换，当前步高亮；
  - 每一步的底部只放一个大按钮（「下一步 · 排内容 →」…），与模块条形成双重引导。
- 内部地址：`/admin/creative/pages`（首页）与 `/admin/creative/pages/{id}`（编辑区，四个步骤共用）。

## 3. 行业通用化（承 v0.2，保持不变）

1. **参数=企业自定义**（推荐参数池＋自由新增），参数即"提取与展示口径"，出处与核准要求不变；
2. **板块=通用内容块库**（参数规格/图片/图纸与尺寸/应用场景/认证/对比/资料下载/FAQ…），可增删、排序、改标题；
3. **标准模板（推荐）** 去行业词；示例数据通用化；
4. **边界如实标注**：自定义参数首版覆盖 提取匹配（文本级）→人工录入→展示→缺项；问答/匹配字段选择沿用既有清单（后续增强）。

## 4. 首页＝产品视角列表（本轮重设计）

**首页就是"当前企业的产品 × 展示页"一览**，用户一眼看清哪些产品已经有展示页、哪些还没有：

```
产品展示页                                        [ ＋ 新建展示页 ]
买家点开产品后看到的页面，都在这里管理。

（首访教练条）第一次设置？每个品类做一份：选参数 → 排内容 → 看效果，约 5 分钟。

┌─ 工业输送设备 · 产品展示页     [已上线 v2]
│  覆盖产品（2）：AX-500、AX-300
│  有改动还没发布（线上仍是 10-02 的版本）· 更新：张工          [看效果] [继续编辑]
├─ 灌溉阀门 · 产品展示页          [有改动还没发布]
│  覆盖产品（3）：V-100、V-200、V-300 · 更新：李工             [继续编辑]
├─ 减速电机 · 产品展示页          [尚未设置]
│  覆盖产品（1）：DM-200 · 买家目前看到平台标准样式             [开始设置]
└─ …（每个品类一组；组内产品点开可看产品详情）
```

- **行 = 一份展示页（一个品类）**：品类名 + 状态 + **覆盖的产品清单**（型号，可直接点进产品页）+ 下一步按钮；同类产品共用一份展示页（新增产品自动适用，发布后生效）。
- 保留你点赞的 **「看效果」「继续编辑」**；未设置的行给 **「开始设置」**。
- **[＋ 新建展示页]＝必须先选产品（拍板 q2 补充）**；**交互：点击按钮后，"选择产品"卡片才在标题下方内联展开（默认隐藏、再点收起；非弹窗、不跳页）**：
  1. 从**本企业产品库**选择对应产品（下拉，只含本企业产品；产品库为空则引导先去「产品管理」添加产品）；
  2. 系统显示"将归入：某品类；该品类覆盖产品：AX-500 等 N 个"；
  3. 若该品类已有展示页 → **直接打开现有页并提示**；没有 → 创建新展示页。
  - **只能对产品库中的产品建页**：选择器不提供库外产品；没有产品就没有可建页的对象。
- 空态（企业还没有产品/品类）：一张卡引导去「产品经营 › 产品管理」；三步引导卡只在空态和首访教练条上出现，不占据列表屏主体。

## 5. 编辑区（四步流程，同屏切换）

> 顶部为 §2 的模块条；每屏结构 = 页头（名称+状态+已自动保存）→ 当前步骤内容 → 底部大按钮。

### 步骤 1「选参数」
参数卡片列表（中英名+单位+开关+排序+行内展开编辑/删除）＋「从推荐里加」chips ＋「＋自定义参数」。
微文案："这些是买家在页面上看到的规格。数值来自你上传的资料，你确认过才会展示。" 底部：**[下一步 · 排内容 →]**。

### 步骤 2「排内容」
内容板块卡片列表（开关/排序/改标题）＋「从板块库添加」；折叠区：AI 助手设置（进阶，默认关闭）、分组名称、版本记录。底部：**[下一步 · 看效果 →]**。

### 步骤 3「看效果」
买家视角预览（黄色横幅"预览·未发布"）+ 试看产品下拉 + 中英切换。底部：**[满意，去应用 →]** ＋ [返回调整]。

### 步骤 4「产品页联动」（发布与应用）
- 顶部状态卡：这份展示页的线上版本与未发布改动说明（大白话）。
- **关联产品列表**：覆盖产品（型号）｜各自"当前使用的展示页版本"｜是否需要"重新发布产品"才套用（带「去产品页 →」）。
- **发布动作（按权限）**：
  - 员工：**[提交给管理员]**；
  - 管理员：**[确认上线]** ＋ **[撤回]**；
  - 微文案："确认上线后，还需在对应产品上「重新发布」，买家才能看到新版本——**在此之前线上完全不受影响**。"
- 底部附"产品页里长什么样"的小示例（产品核对页的「展示页」卡）。

## 6. 数据模型（与 v0.2 相同，仅绑定说明细化）

```sql
templates(id, tenant_id, is_platform, category, name, status, draft_json,
          draft_updated_by, draft_updated_at, published_version, created_by, created_at, updated_at,
          UNIQUE (tenant_id, category))
template_versions(id, tenant_id, template_id, version, content_json, status,
          approved_by, approved_at, created_by, created_at, UNIQUE(template_id, version))
```
- 内容 JSON：`params[]`（自定义参数）· `groups[]` · `blocks[]` · `advanced.ai_prompts`（同 v0.2）。
- **创建流程**：选择产品 → 取该产品的已核准品类 → 该品类无展示页则创建（UNIQUE(tenant_id, category) 兜底并发）；已有则直接打开。
- 发布快照 `product_versions.snapshot_json` 追加 `"template": {template_id, template_version_id, version, source}`。
- 模块：`GRANTABLE_MODULES` 增加 `("creative", "创意中心")`；**授权勾选 UI 在成员管理页**；`/admin/creative` 前缀 → `module:creative`。

## 7. 硬边界与不变式

1. 默认（标准模板）渲染 = 现状页面（回归锁）。
2. 未核准事实不进页面/匹配/问答；**展示可自定义，事实不放松**。
3. 未发布改动不影响线上；发布冻结版本；旧 RFQ 与历史快照不被静默改写。
4. 仅管理员可「确认上线/撤回」；模板与版本全租户隔离；平台标准模板全员只读。
5. 界面主路径无技术术语、无数字标识（走查项）；高级能力默认折叠且注明"不改也完全能用"。
6. **只能对产品库中的产品建页**；创建必经"选择产品"。

## 9. 分期

- **Phase 1（拍板后开工）**：creative 模块+成员管理勾选 → 首页（产品视角列表+选产品创建）→ 四步编辑区（参数/板块/预览/自动保存）→ 产品页联动（提交/确认/撤回/关联产品）→ 引用冻结 → 审计 → 回归锁 → 走查与文档。验收点 1–15。
- **Phase 2**：自定义参数的问答支持；AI 助手设置联动打磨；分组高级编辑；板块库扩充。
- **Phase 3（长期）**：3D/CAD 来源标记与生成类（F-10/F-11）、跨企业模板（F-14）。
