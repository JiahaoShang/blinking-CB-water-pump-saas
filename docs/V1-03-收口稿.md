# V1-03 收口稿 · 「创意中心 / 产品展示页」设计器 —— 冻结清单与实施拆分

**状态**：✅ 已收口（2026-10-05）。设计阶段到此结束；开发依本稿实施。
**配套基准**：《V1-03-企业模板库-设计稿.md》（定稿）＋线框 `design/template-library-wireframe/index.html`（v0.3c）。
**范围**：仅「创意中心 › 产品展示页」；外部渠道（WhatsApp / Telegram / 企业微信）按用户要求继续暂置。

**一句话**：让任何行业的普通业务人员，不靠说明书、十分钟内，为企业产品做"买家点开就能看到的"产品展示页；改动只在「确认上线 ＋ 产品重新发布」后对买家生效。

## 二、冻结清单 A：参数

**A1 通用推荐池（首批 14 项）**
型号、材质、尺寸、重量、颜色、功率、电压、容量、转速、压力、精度、工作温度、防护等级、接口
（＋「自定义参数」自由新增；每项含中英名、单位可选、排序、开关）

**A2 兼容保留（现有 8 个字段，不弃用）**
材质、功率、安装尺寸、流量范围、扬程范围、介质适用条件、介质温度、性能曲线目录点
- 存量与演示产品的参数、提取、问答不受影响；
- **提取支持边界（首批，如实标注，不臆造）**：现有字段支持自动提取；新增自定义参数首版走 提取匹配（文本级）→ 人工录入/确认 → 展示 → 缺项，不进问答与匹配（增强项记入备忘录）。

**A3 硬线**：数值必须来自已核准事实；未核准不进页面、不进问答（沿用现状不放松）。

## 三、冻结清单 B：板块库（首批 12）＋ 标准组合

**B1 板块库**
首屏（固定不可关）｜要点速览｜参数规格｜图纸与尺寸｜图片与图库｜型号对比｜应用场景｜定制能力｜制造与质检｜认证与案例｜资料下载｜常见问题
（可开关 / 排序 / 改标题；标题留空＝默认文字）

**B2 标准模板默认组合 ＝ 现状公开页等价（回归锁基准，自上而下）**
首屏 → 要点速览（"已核准资料能说明什么"）→ 参数规格 → 图纸与尺寸 → 型号对比 → 应用场景 → 定制能力 → 制造与质检 → 认证与案例 → 资料下载 → 常见问题 →（固定附属：发起询价、在线聊天、语言切换、页脚）
- 实施规则：若与现状页面结构有任何出入，**以现状页面为准**调整默认组合（回归锁 ＞ 清单）。
- 去行业词**审定变更项**（随实施逐条列明）：面包屑中间项"水泵"→ 通用词；默认文案逐条检查。

**B3 条件与缺项**：同现状——无已核准内容时如实显示说明文字（不臆造）；未获准公开的文件不出现。

## 四、冻结清单 C：UI 规则（审阅反馈，硬约束 10 条）

1. 模块条唯一置顶、无数字、连线递进（§一.6）；
2. 首页 ＝ 产品视角列表（三态＋覆盖产品＋按钮）；
3. 新建卡：点击展开、内联、默认隐藏、非弹窗、再点收起；
4. 创建必经"选择产品"（选择器仅含本企业产品库）；
5. 发布动作在「产品页联动」步；
6. 授权入口在成员管理（企业管理内）；
7. 按钮 ＝ 该状态下"下一步动作"（看效果/继续编辑/开始设置/下一步·X/提交给管理员/确认上线/撤回）；
8. 状态说人话：`已上线 vN` / `有改动还没发布` / `尚未设置`；
9. 自动保存 ＋"已自动保存 时间"；每次改动都说明"不影响线上"；
10. 主路径术语与数字化检查（§五）。

## 七、实施须知与风险

- 基线：**245 项测试全绿**（`PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -q`）；每切片先测后交；本地提交、只 `git add` 自己文件（工作树有并行协作者）；不推 GitHub、不覆盖主路径。
- 回归锁方法：默认（标准模板）渲染与现状公开页做**结构与关键内容对照清单**，逐条核对；有出入 → 以现状为准并回改默认组合。
- 风险备注：
  1. "提取匹配（文本级）"的落地口径在切片 3 实施时必须写死；**达不到就如实降级为"人工录入"，不臆造能力**；
  2. 预览与公开页渲染必须同源（参数化同一函数），禁止复制分叉导致两套行为；
  3. 存量产品（演示数据）页面必须不受影响（回归走查覆盖）；
  4. 演示门控（工具/端点仅管理员、默认关闭）不受本批影响。
- 渠道对接：保持暂置；本批不涉及。
