日期：2026-10-14。来源：用户本窗口明确要求修复；本地 Hermes 实施，Codex 独立审查、测试与实机界面验收。状态：**F-6 / T5-N02 已修复并通过本范围验收；仅部署受邀测试实例，未公开上线。**

## 改动与边界

- 有效 `/rfq/{token}` 从该询价记录的 `tenant_id` 读取企业当前名称并 HTML 转义；填写、校验失败、提交及修订成功均使用同一身份。请求参数、匿名默认企业不能决定显示名称。
- 无效、撤销、非渠道及畸形 RFQ 链接显示中性 `Growave` 与 404；不泄露企业名称。实机初验发现过短链接落入通用页面后补修，并增加 GET/POST 回归。
- 独立 RFQ 页去除固定水泵供应商、DEMO 及不存在的产品区块导航；表单、版本、负责人、联系同意及渠道关联规则沿用原实现，保留 no-referrer。
- 其他公开产品页仍按原实现；本项通过不代表所有公开页面已正式化，也不替代 T3 真实企业名称和资料核准。
