
List objects under a prefix or all buckets.
To run this command, you must have the oss:ListObjects permissions.
If using metadata-filter, you must also have the oss:GetObject permissions.

Usage: ossutil ls [oss://bucket[/prefix]] [flags]

Aliases: ls, list

Examples:

1) List all buckets
  ossutil ls

2) List all objects in the bucketexample bucket
  ossutil ls oss://bucketexample

3) List all objects under the dir prefix in the bucketexample bucket
  ossutil ls oss://bucketexample/dir

4) List objects under the current dir directory in the bucketexample bucket
  ossutil ls oss://bucketexample/dir -d

  Note: There is no directory hierarchy in the bucket, and this command needs to scan all objects under the prefix, the more objects, the more time spent. 

5) List at most 100 objects under the dir prefix in the bucketexample bucket
  ossutil ls oss://bucketexample/dir --limited-num 100

6) List the objects with ".txt" suffix under the dir1 and dir2 prefix in the bucketexample bucket
  ossutil ls oss://bucketexample/ --include "/dir1/**.txt" --include "/dir2/**.txt"

7) List the objects created within three days in subdirectory dir1 and dir2 under the rootdir dir in the bucketexample bucket
  ossutil ls oss://bucketexample/rootdir/ --include "/dir1/**" --include "/dir2/**" --max-age 3d

8) List all buckets with resource group ID 'rg-123'
  ossutil ls --resource-group-id rg-123

  Note: Use "ossutil filter" for more information about filter flags.
