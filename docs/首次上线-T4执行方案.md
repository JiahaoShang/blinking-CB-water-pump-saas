## 3. 一致性边界（如实声明）

SQLite 快照为事务一致；原件与私有目录在快照之后顺序复制，无全局锁。并发上传时可能出现“库行已提交、文件为部分写入/新旧混合”。要得到互相匹配的一套备份（库 + 原件 + 私有配置 + 桥状态），须先停止应用与渠道桥（停止写入与后台 worker）再备份——`deploy/backup_snapshot.sh` 即该停写流程（systemd stop → 备份 → start）。本工具不把“先库后文件”称为原子快照。
