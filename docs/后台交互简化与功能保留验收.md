# 后台交互简化与功能保留验收

日期：2026-10-10。来源：用户要求降低其他后台模块的信息密度、学习成本，改善首次使用引导，并明确保留全部现有功能。状态：本地界面增量已验证。

## 范围与呈现原则

覆盖现有后台中文模块及其详情页。渠道接入、Telegram / WhatsApp / WhatsApp（个人版）收件箱保持现版。买方页面、权限判断、业务接口、数据模型及资料核准规则不变。

先展示当前业务、待办与主操作；历史、诊断、扩展设置按需展开。引导说明对应模块的实际操作，不把开发聊天当作产品入口。折叠只改变呈现，不删除原 DOM 表单或数据；关闭 JavaScript 时仍可使用原有完整页面。

| 模块 | 本轮呈现调整 |
| --- | --- |
| 管理概览 | 明确从待办开始，模型诊断按需展开；零授权账号维持等待授权页面 |
| 销售工作台 | 客户名称优先、完整编号保留；筛选按需展开，当前筛选默认展开；详情保留处理和回复，跟进节点与历史分层，停止主动联系操作独立展开 |
| RFQ 询价 | 客户与型号优先；需求快照、逐次修改记录按需展开 |
| 人工任务 | 明确阅读问题、补充条件、提交答复的流程，原追问和答复操作保留 |
| 网站聊天 | 从最新消息进入；关联资料按需展开，消息、回复和 AI 开关保留 |
| 企业知识 | 按产品展开知识与来源，首个产品默认展示；对内/对外规则保留 |
| 产品管理 | 页首新建入口；品类、来源可直接定位并展开；混合状态时优先查看待核字段，全部字段可切回；使用范围设置与核准操作分开呈现 |
| 产品展示页 | 沿用原分步流程；参数和板块的显示开关保留，编辑/排序/删除集中到每项的展开入口，扩展库与制作说明按需打开 |
| 分析报表 | 首屏保留询价结果，其余分析主题按需展开；导出和明细保留 |
| 成员管理 | 页首创建成员入口，原成员状态与模块授权保留 |
| 网站 API 接入 | 页首登记入口；已有网站时收起新增表单，原标识与接入说明保留 |
| 企业设置 | 四类设置独立展开；保存后仅展开对应设置并显示反馈 |
| 操作记录 | 明确筛选与核对流程，长变更记录使用“查看变更详情”入口，原完整记录保留 |

详情页的本页导航会展开目标区域；隐藏区域触发浏览器必填校验时自动展开。原处理状态、停止联系提示、核准风险提示与主提交操作不自动折叠。
