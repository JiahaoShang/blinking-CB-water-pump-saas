# 水泵产品详情页高保真原型

**状态**：内部可点击设计稿，不连接业务 API，不创建真实 RFQ。页面默认英文，可切换中文。静态文件需通过本地 HTTP 服务打开，例如在仓库根目录运行 `python3 -m http.server 8765`，然后访问 `http://127.0.0.1:8765/design/product-detail-highfidelity/`。

## 14 个区块

1. 吸顶企业导航（演示品牌）
2. 面包屑
3. 产品首屏、图库、关键事实、MOQ/交期/样品状态与三个操作
4. 六项吸顶锚点导航
5. 产品优势及其证据边界
6. 分组参数、尺寸示意与来源
7. 三列型号横向对比及询价预填
8. 三种系列应用场景
9. 定制问题与虚构流程示例
10. 制造与质量控制证据缺口
11. 认证与客户案例证据缺口
12. 四类资料与公开许可状态
13. 常见问题
14. 询盘表单和页脚

桌面图库有缩略图、左右键、上一张/下一张、1–3 倍缩放和放大后拖拽；没有自动或循环播放，也不依赖 CDN。手机布局改为图在上、圆点分页、纵向按钮与固定底部操作条；型号表保留横向比较，可左右滚动。表单仅做前端校验并明确显示**没有发送或保存**。

## 数据与素材怎样替换

- `index.html` 中 `3SV08NL007T` 的目录点和型号说明来自本地 `fixtures/lowara_demo_seed.json`、`B2B_Pump_Demo_Research/Lowara/_数据详情.md` 与 Rev. B 技术目录记录。型号/系列范围和 CAD 文件名映射须由卖家授权人员复核；页面目前标为内部演示。
- 比较表的 `SYN-PUMP-B`、`SYN-PUMP-D` 以及任何定制流程天数均为**虚构测试值**；实际发布时替换为另两个经核准的真实型号，或诚实显示不足三款，不得以合成型号对外宣称在售。
- `assets/*.webp` 是现有本地 CAD 预览 PNG 的 WebP 格式转换，未增添工程细节。替换产品图时更新 `app.js` 的 `slides` 数组、图片说明与资料来源。`dimension.svg` 是无尺寸数值的编辑性示意图，不是工程图。
- 文案的英文正文位于 `index.html`，中文对应放在 `data-zh`；新增内容需同步两种语言、单位与引用。不适用水泵的连接器字段、认证或工厂宣称不能套用。
- 资料下载区目前**没有公开直链**。卖家确认具体文件、型号、版次与许可后，才由正式产品的受控文件接口开放。页内询盘表单须接入 [统一 RFQ API 契约](../../docs/MVP-数据与接口契约.md)，与官网聊天入口共用会话、RFQ 编号与销售队列。

## 上线前检查

1. 卖家核准全部可见技术事实、单位、来源层级与英文译文；缺项保持缺项。核准三个真实型号或移除未核准的比较列。
2. 核实企业名称、Logo、联系方式、MOQ、交期、样品、定制能力、流程时限、工厂照片、质检项目、认证及案例；有证据才发布承诺。
3. 核实产品图、2D/3D、PDF、STEP/DXF 的型号映射、公开使用许可及下载鉴权；不能以本地静态链接代替。
4. 接通产品版本、匿名会话凭据、页内 RFQ、联系人确认、幂等和错误回退；从聊天推荐页新开标签时保持原会话，直访者建立独立会话。
5. 用桌面与手机实际浏览器测试中英切换、图库键盘和拖拽、表格横向滚动、表单失败保留输入、打印和无障碍。

该原型展示交互与视觉方向，不代表 MVP M2/M6 功能已开发或验收。
