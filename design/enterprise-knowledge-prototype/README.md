## 怎么打开

方式一（最简单）：直接双击 `index.html`（或拖进浏览器）即可。

方式二（本地预览，推荐给需要固定地址的评审）：
在仓库根目录启动静态服务后访问：

```
python3 -m http.server 18868 --bind 127.0.0.1 --directory design/enterprise-knowledge-prototype
http://127.0.0.1:18868/
```

（18868 为评审约定端口，可换成任意空闲端口；原型自身不依赖该端口。）

## 5 分钟体验路径（建议按顺序）

1. **列表**：看 12 条演示知识——每行只有一枚状态标签，且已发布条目只有两种文案：「已发布（AI客服可用）」/「已发布（AI客服不可用）」，两者**配色区分**（可用为绿色、不可用为中性蓝灰；只有文案与颜色不同，不可用原因另行提示）。用搜索框搜"保修"：出现结果后搜索框右侧出现线稿「×」清空按钮——点击只清空关键词（分类/状态等筛选保留）、列表即时刷新、焦点回到搜索框；清空后按钮自动隐藏。
2. **详情**：打开「2026 秋季展会接待与报价政策」——状态是"已发布（AI客服不可用）"，原因是"过期"（辅助提示，不是额外状态）。右侧属性栏只有：分类 / 用途 / AI授权 / 关联对象。
3. **字段级过滤**：打开「3SV08NL007T 立式多级离心泵」——字段表里"内部成本口径"标着"仅内部"；点属性栏的"允许 AI 客服使用"并确认。
4. **模拟客户问答**（侧栏）：先问「工厂参观怎么申请？」（内部资料 → 转人工），再问「3SV08NL007T 的流量和扬程是多少？」（刚才已授权 → 带引用答复，点引用卡跳回资料）。页内已标注"演示，不调用模型"。
5. **编辑与发布**：打开「整机保修与售后响应政策」→ 编辑 → 保存草稿（线上 v3 不受影响）→ 发布（对外+授权需一次确认）→ 短暂"准备中"后恢复可用（模拟）。
6. **失败重试**：打开「GX-9 变频供水机组」→ 看到"处理失败"→ 点重试。
7. **停用**：打开「发货与物流常见问题」→ 停用（确认对话框）→ 回问答测试问"发货要几天？"——立即变成转人工（演示"立即生效"）。
8. **文件导入**：右上「添加知识 → 上传文件」（在「文件资料」视图里是直接的「上传文件」按钮）→ 选一个本地 TXT/MD（≤1MB，只在本地读取预览）→ 改标题/正文/用途 → 保存草稿；PDF/Word 会提示"登记原件、人工整理正文"。导入页写明"演示，不上传"。
9. **未保存保护**：在导入或编辑里有改动时点击其他导航 → 弹"未保存的修改"三选一；导入场景的"保存草稿并离开"会把内容存为草稿，标题为空时会明确阻止并说明（不丢内容）。
10. **权限视角**：顶栏切到「仅阅读成员」→ 编辑类操作全部隐藏、显示只读说明（仅演示界面差异）。
11. **来源与版本**：保修政策详情 → "来源与版本"页签 → 对 v1 恢复为草稿（创建新草稿，不覆盖历史）。
12. **手机尺寸**：把窗口缩到 390 宽（或手机打开）——侧栏变抽屉、列表堆叠、字段表横向滚动。
13. **侧栏折叠导航**：默认分类收起——「全部知识」是主按钮：点击进入全部列表**并展开分类**；主按钮右侧的独立箭头只展开/收起（不跳页）；进入产品与服务 / 文章与 FAQ / 文件资料任一子视图后保持展开、当前项高亮。
14. **分视图新增入口**：产品与服务视图右上直接显示「添加产品 / 服务」、文章与 FAQ 视图显示「添加文章 / FAQ」、文件资料视图显示「上传文件」；只有「全部知识」保留通用「添加知识」下拉；切到「仅阅读成员」视角后不出现任何新增入口。

## 演示边界（务必了解）

- 「准备中 2 秒后完成」「处理失败重试」「关键词匹配答复」都是**前端模拟**，用于表达交互反馈；不代表真实系统的处理时间、失败率或模型行为。**平台真实模型尚未接通，本原型不证明通用问答已实现。**
- 权限视角切换只演示"界面隐藏"，**原型未验证后端隔离**——真正的权限强制必须由后端实现和测试保证。
- 每个企业资料独立、只读授权等规则是**设计规则**；原型用一个演示租户表达，不构成多租户实现。

## 已知演示限制（不承诺已验证）

- 模拟回答使用预置答案；新增或修改正文后不会重新生成对应答案，不能据此验证新版内容的真实问答效果。引用呈现与可用性过滤用于交互评审，真实版本内容与答案的一致性属于后端验收。

- **分类是示例**：原型里的分类（FAQ、服务政策、企业文化、培训、文件资料、产品、专业服务）只是预置下拉样例，用于演示"分类是筛选条件"。**内容形态（产品/服务/文章/FAQ/文件来源）与主题分类不应强绑定；"分类可自由新增/重命名"和完整的通用 Schema 配置未在原型中实现，也不宣称已验证**——是否/何时实现见 PRD 的待评审项。
- 产品/服务的字段模板是简化的默认演示模板（没有跨产品自定义字段设计器），不代表生产固定字段。
- 文件导入只演示 TXT/MD/CSV 的本地文本读取；PDF/Word 自动解析属后续批次，原型不模拟。
- 历史版本的"恢复快照"只为演示条目准备了少量快照，其余版本显示"演示未保存该版本快照"。
