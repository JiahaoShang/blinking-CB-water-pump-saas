## 体验路径（约 3 分钟）

1. **文件资料列表**：三条代表性内容——「客户服务政策」（已发布 v2 · 绿色）、「新员工培训资料」（草稿）、「扫描版产品手册」（导入记录区，任务进度「无法识别」+ 原因；导入进度不是知识状态）。搜索出现「×」——点击只清关键词，形态/状态筛选保留、焦点回到搜索框。
2. **添加资料（第 1 步）**：文件资料右上「上传文件」→ 只需要选文件（点「演示样例：PDF / DOCX」或选本地文件——只记录文件名）。**默认通用文档，不必先学模板**；知识模板在「补充信息（选填）」折叠里，可随时选；未选择文件不能继续（按钮禁用并写明原因）。
3. **检查内容（第 2 步）**：标题 + 单一进度「还需检查 N 段」+ 逐段正文，每段短标签「收录 / 已核对」（未收录段落保留在私有来源）。点段落「来源 · 第 x 页」→ 原文对照自动展开、翻到对应页并高亮（对照文本是演示，非真实 PDF/Word 渲染）。「补充业务信息（选填 / 还有 N 项必填）」折叠里有模板字段；没有模板时给出「选择知识模板…」引导。内部段落默认不勾选「收录」；混合文件提供两种处理按钮，保持仅内部内容不进对外 AI。
4. **发布设置（第 3 步）**：顶部短摘要 + 唯一一处编辑用途（内部 / 对外）、AI 授权开关（默认关闭）、折叠的到期时间（datetime-local 精确北京时间，留空 = 长期有效）。未完成项只列未通过项，点击可回到第 2 步对应位置；「保存草稿」次按钮、「发布」主按钮；对外 + 已授权发布弹一次确认（列明用途、AI 范围、有效期），取消不改动。发布后失败由折叠的「演示场景」切换模拟。
5. **替换文件（版本）**：详情「更多操作」→「替换文件…」→ 载入演示样例（对照区列出「文字有变化 / 新增段落 / 未匹配」，只是文本对照）→ 保存草稿：旧 v2 继续可用，详情出现「替换文件草稿」；继续编辑草稿 → 发布 → 变 v3；发布失败也不回退旧版。
6. **模板与升级**：侧栏「知识模板」（仅管理员视角）→ 编辑「服务方案模板」（改名 / 类型 / 必填 / 单位 / 选项、上移下移、删除、添加；预览按需展开）→「保存为新版本」。打开「上门安装服务方案」→ 字段页「采用新版模板（v2）」→ 确认后**直接进入第 2 步**（无需重选文件），旧值 / 来源 / 历史保留、发布版本不变；取消不改任何值。
7. **返回入口**：任意知识详情顶部「返回文件资料 / 返回产品与服务 / 返回文章与 FAQ / 返回全部知识」→ 回到实际进入的列表，搜索与筛选保留；只读视角同样可用；不依赖浏览器历史。模板编辑页有「返回模板列表」。
8. **未保存保护**：核对页或模板编辑器有改动时点其它导航 → 弹「未保存的修改」（保存草稿并离开 / 放弃修改并离开 / 继续编辑）；模板编辑器只有放弃 / 继续。Escape 取消、焦点回到原按钮。
9. **只读视角**：顶栏切「仅阅读成员」——无上传、编辑、模板入口；正文 / 字段 / 来源 / 历史仍可读（含仅内部资料）。
10. **手机尺寸**：缩到 390 / 320 宽——侧栏变抽屉、正文单列、折叠区可用；模板编辑页在 320 不再有页宽溢出。

## 演示边界（务必了解）

- **演示说明与场景控件**：顶部常驻只有「设计预览 · 数据为演示，刷新重置」，其余评审 / 权限 / 技术说明折叠在「预览说明」；识别五种情况与「发布后处理失败」折叠在「演示场景」评审控件里，默认不展开、不混入主流程。
- **文件识别**：不读取任何本地文件；「演示样例：PDF / DOCX」直接给出预置识别结果，五种「演示场景」（识别成功 / 扫描件 / 旧版 DOC / 加密 / 损坏）由评审控件直接切换，**没有用倒计时冒充处理过程**。
- **发布结果**：「处理正常 / 处理失败」也是演示场景切换；真实系统的识别与处理是后端异步任务，失败原因与重试以真实实现为准。
- **字段**：只支持 文字 / 数字+单位 / 选项 / 日期 / 是·否 五种类型与简单列表排序；**没有**公式、跨字段换算、重复组或字段间关联。
- **映射**：段落→字段完全是手动选择与手填；原型不演示、也不承诺「自动识别字段」。
- **权限**：视角切换只演示界面隐藏，未验证后端隔离；模板管理沿用「管理员 / 产品管理授权成员」是评审建议（P2-02），未实现。
- **导入限制**：≤10MB / ≤200 页是评审建议（P2-05），原型只是文案提示，不做真实校验。

## 第二轮 UX 改版（2026-10-11，用户实走反馈）

只改本原型文件（HTML / CSS / JS / 回归 / README），未动业务代码、数据库、docs 与第一批原型。

1. **返回入口**：所有知识详情顶部「返回…」按钮，按实际进入的列表返回（记录列表来源），保留搜索与筛选；只读同样可用；不依赖浏览器历史。模板编辑页「返回模板列表」沿用未保存保护。
2. **顶部演示条缩短**：常驻「设计预览 · 数据为演示，刷新重置」；其余评审 / 权限 / 技术说明收进「预览说明」；顶栏重复 chip 与侧栏底部重复说明删除。
3. **三步收敛**：添加资料 → 检查内容 → 发布设置；每步一句当前任务 + 一个主动作。
4. **默认通用文档**：第 1 步只要求选文件；模板移到「补充信息（选填）」；未选模板可完整走完；替换 / 升级的模板规则不变。
5. **检查内容正文优先**：标题 + 单一进度「还需检查 N 段」；原文对照默认折叠、点「来源」展开定位（并修复跳转后页码标签不更新的问题）；字段区折叠为「补充业务信息（选填 / 还有 N 项必填）」，缺项或已选模板自动展开。
6. **发布设置唯一位置**：用途、AI 授权（默认关闭）、精确到期时间只在第 3 步；未完成项只列未通过项、可点击返回；保存草稿 / 发布与对外确认保留。
7. **模板编辑减负**：一行引导；固定字段与规则折叠为「查看固定信息与填写规则」；每行控件按类型显示；预览折叠；模板列表用自然业务词；改名 / 类型 / 旧版本、显式升级、历史保留不变。
8. **演示场景折叠**：识别五种情况与发布失败控件默认折叠，不混入主流程；错误、不能发布原因与授权确认不隐藏。
9. **320/390 修正**：模板字段行动作合并（去掉隐式第 5 列导致的 16px 溢出）+ 单列兜底；「更多操作」菜单小屏左对齐；宽度测量无页面级溢出。

保持不变的规则：收录 / 核对、必填、内部段落默认排除、字段核准与 AI 许可、到期与发布确认、版本闸门、升级 / 替换草稿语义；绿色与蓝灰颜色 token 未改。详细改动日志见 `evidence/second-pass-checks.log`。
